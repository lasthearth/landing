# AGENT_RULES_MAP.md — правила и расхождения

> **Что это.** Сверенные с кодом правила, которые **не продублированы** в других документах,
> и таблица расхождений «документация ↔ реальность». Ветви задач — в `AGENTS.md`.
> Читайте этот файл до правки, если сомневаетесь, чему верить.

## 1. Источники истины

| Вопрос                                    | Истина                                       |
| ----------------------------------------- | -------------------------------------------- |
| Границы слоёв, структура                  | код + `npm run arch`                         |
| Что где лежит, какие роуты, какие словари | `docs/project-map.md` (генерируется из кода) |
| Почему так сделано                        | `docs/history.md`                            |
| Дизайн, i18n, API, поселения              | `docs/*.md`                                  |
| Контракт бэкенда                          | `API_CONTRACT.md` + живая спека              |

При противоречии документа и кода — верить коду, а документ поправить в том же коммите.

## 2. Форматирование и бюджеты

- `.prettierrc`: 4 пробела, ширина 120, одинарные кавычки, `semi`, trailing comma es5, LF, финальный newline.
  HTML — двойные кавычки, `htmlWhitespaceSensitivity: ignore`; JSON — двойные кавычки, 4 пробела.
- `.editorconfig` дублирует это для редакторов; конфликтов с prettier нет.
- Бюджеты сборки (`angular.json`): initial warn 1.4 MB / error 1.8 MB; `anyComponentStyle` 12/18 kB.
- Бюджеты агентских документов: `AGENTS.md` ≤ 8 kB, прочие ≤ 48 kB, `docs/history.md` ≤ 120 kB
  (проверка — `npm run context:cost`).

- Список веток и их состояние — `docs/history.md` §7.1.

## 5. Известные нестабильности

- `ng build` в песочнице с перехватом вывода падает на `esbuild` (`EPERM`, spawn) — ограничение окружения,
  а не проекта: в обычном терминале сборка проходит. В песочнице типы проверяет `tsc --noEmit` из `npm run verify`.
- Пререндер `/unauthorized` ранее падал с `TimeoutError`; роут-редирект убран из `routes.txt` (`docs/history.md` §8).
- `npm test` требует Chrome; без него тесты не запускаются (`docs/TOOLING.md`).
- Легаси-нарушения границ FSD зафиксированы в `scripts/architecture-baseline.json` — `npm run arch` валит только новые.

## 6. Порядок работы

1. Определить слой и слайс (`docs/ARCHITECTURE.md`), найти существующее в `docs/project-map.md`.
2. Внести правку по правилам из `AGENTS.md`.
3. Прогнать `npm run verify`.
4. Создали или перенесли файлы — `npm run map`. Приняли решение с обоснованием — запись в `docs/history.md`.
5. Коммит в стиле проекта (в своём терминале: `git` в песочнице не пишет индекс).
