# Ловушки проекта

> **Что это.** Короткий список мест, где разумное на вид решение ломает проект.
> Домен поселений — в `docs/SETTLEMENTS.md`, API — в `docs/API.md`, UI — в `docs/DESIGN_SYSTEM.md`.

| Ловушка                               | Почему так и что делать                                                                                                                                                                                                                                                                                |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `errorInterceptor` глотает GET-ошибки | Он показывает алерт и возвращает `EMPTY`. Чтобы обработать самому — `SKIP_ERROR_ALERT` + гейт по праву до подписки (`docs/API.md`)                                                                                                                                                                     |
| Вечный скелетон после сбоя GET        | `EMPTY` приходит **до** `catchError` компонента: поток не выдаёт значения и не завершается, поэтому `loading` не сбрасывается, а `finalize` не срабатывает. Для пары состояний «пусто / ошибка» берите поток, который пробрасывает сбой (`getShopItemsOrThrow$()`, `SKIP_ERROR_ALERT` в своём сервисе) |
| Decimal как число                     | `coins`, `price`, `reward_coins` — строки в DTO и UI; `Number()` ломает точность                                                                                                                                                                                                                       |
| Интерполяция с сервера                | `role.name`, `contact_info` и любой серверный текст — только `{{ }}`; `innerHTML` = XSS                                                                                                                                                                                                                |
| Словарь не загружен на роуте          | Тексты приезжают с роутом через `loadPage()`; проверьте роут, а не только словарь (`docs/I18N.md`)                                                                                                                                                                                                     |
| Хардкод цвета                         | Только токены `--lh-*`; hex в классах ломает тёмную тему и WCAG-проверку                                                                                                                                                                                                                               |
| `transition: all` и дефолтные `ease*` | Дают дрожание и чужую физику; берите `--lh-ease-*` и перечисляйте свойства                                                                                                                                                                                                                             |
| Кликабельный `div`                    | Ломает клавиатуру и скринридеры: нужен `button`/`a`                                                                                                                                                                                                                                                    |
| Новый роут без режима рендера         | Неизвестное уводит `**` в `src/app/app.routes.server.ts`; страницу под авторизацией это замедлит, а пререндер её не соберёт. Редирект-роут в `RenderMode.Prerender` роняет сборку (`TimeoutError`)                                                                                                     |
| Правка `rules.i18n.ts` целиком        | 250 kB / 922 ключа: используйте `npm run i18n -- set rules <ключ> "<текст>"`                                                                                                                                                                                                                           |
| Импорт из внутренностей слайса        | Только через `index.ts` слайса; проверяет `npm run arch`                                                                                                                                                                                                                                               |
| `npm test` без браузера               | Karma требует Chrome. В агентском окружении его нет — см. `docs/TOOLING.md`                                                                                                                                                                                                                            |
| `@defer` и пререндер                  | Тяжёлые виджеты уводите в `@defer (on idle)`: иначе они возвращаются в начальный бандл                                                                                                                                                                                                                 |
| Второй файл окружения                 | Окружение только в `src/app/core/config/environments/`: дубль в `src/environments/` правки не применял (файлы удалены). Ловит правило `strayEnvironment` в `npm run arch`                                                                                                                              |
| `shareReplay(1)` поверх GET           | Кэширует и неудачу: `errorInterceptor` отдаёт `EMPTY`, подписчик без значения зависает в скелетоне. Берите `share({ connector: () => new ReplaySubject(1), resetOnError: true, resetOnComplete: false, resetOnRefCountZero: false })`                                                                  |
| Новая вкладка профиля без навигации   | Панель навигации профиля рисует `landing.component`, и только для ключей из `isProfilePage()`. Новый дочерний роут `profile/*` добавляйте и туда, иначе навигация пропадёт                                                                                                                             |
| `i18n -- set` на новый ключ           | Инструмент только меняет существующие ключи: на новый он пишет «ключ не найден» и выходит с кодом 1. Новые ветки дописывайте в словарь руками; паритет ru/en пропуск не поймает                                                                                                                        |
| Апостроф в значении en-словаря        | Разборщик `scripts/i18n-tool.mjs` не понимает экранирование: `\'` внутри значения рассинхронизирует его, и все ключи этой локали после строки молча теряются (инструмент сообщает «ключ не найден в en»). Такие значения пишите в двойных кавычках                                                     |
