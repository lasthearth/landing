# Архив

> **Что это.** Одноразовые артефакты прошлых работ, перенесённые из корня репозитория.
> Агент их не читает и не обновляет; формат в `npm run format:check` они не проходят специально.

| Файл                     | Что это                                          | Почему здесь                                                                                                    |
| ------------------------ | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `rules-edit.md`          | Выгрузка всех правил сервера в Markdown (145 kB) | Генерируемый артефакт; скрипт `scripts/extract-rules.mjs` из репозитория исчез, а файл продолжал висеть в корне |
| `rules-changes.md`       | Список правок правил                             | Разовый рабочий документ                                                                                        |
| `seo-retention-audit.md` | Аудит SEO и удержания                            | Разовый аудит                                                                                                   |
| `seo-retention-fixes.md` | Отчёт по исправлениям (144 kB)                   | Разовый отчёт                                                                                                   |
| `openapi-snapshot.yaml`  | Снимок OpenAPI (274 kB)                          | Дубль живой спеки и `API_CONTRACT.md`                                                                           |

Если что-то отсюда снова понадобилось — верните файл в работу осознанно и добавьте указатель
в `AGENTS.md`, иначе он останется невидимым для агента.
