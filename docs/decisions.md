# Реестр решений

> **Что это.** Быстрые ответы «почему так» со ссылкой на подробную запись.
> Полные обоснования — `docs/history.md`.

| Решение                                                  | Почему                                                                                                            | Где подробно                         |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| Миграция на FSD идёт постепенно                          | Легаси (core/layout/routes) живёт рядом с новыми слайсами; переписывать всё сразу — риск без выгоды               | `docs/history.md` §2                 |
| Каталогов `pages/` и `widgets/` нет                      | Страницы и виджеты остались внутри `features/*`; alias `@pages` есть, но ведёт в никуда                           | `AGENT_RULES_MAP.md` §4              |
| `core` — сквозной слой                                   | Ему разрешено знать про entities/features; иначе гварды и сервисы уведомлений давали бы ложные нарушения границ   | `docs/ARCHITECTURE.md`               |
| Состояние — сервисы и сигналы, без NgRx                  | Масштаб проекта не требует стора                                                                                  | `AGENTS.md`                          |
| Цвета — только токены `--lh-*`                           | Тёмная тема не патчит hex-классы селекторами, а переопределяет значения переменных; контраст проверяется скриптом | `docs/DESIGN_SYSTEM.md`              |
| Свои кривые движения                                     | Дефолтные `ease`, `transition: all` и `blur()` в появлениях давали дрожание и муар                                | `docs/history.md` §6.3               |
| Словари грузятся с роутом (`loadPage`)                   | Правила (224 kB) и юр-страницы (64 kB) ушли из начального бандла                                                  | `docs/history.md` §7.0               |
| Восстановление сессии через `checkAuthIncludingServer()` | Logto даёт access-токен на час, а `checkAuth()` его не продлевает — шапка показывала «Войти»                      | `docs/history.md` §3.-10             |
| Маркер `[GUILD]` в названии поселения                    | Бэкенд не знает типа «гильдия»; маркер режется хелперами на фронте                                                | `docs/SETTLEMENTS.md`                |
| `design/slop-archive` не мержится                        | Приняты отдельные приёмы, остальное отброшено                                                                     | `docs/history.md` §6.3               |
| Гейт архитектуры с бейзлайном                            | 46 легаси-нарушений нельзя починить в один заход: запрещаем новые, старые ведём в `docs/TODO.md`                  | `scripts/architecture-baseline.json` |
| Навигация генерируется, летопись — нет                   | `PROJECT_MAP.md` на 76 kB был одновременно картой, летописью и TODO и потому терял актуальность                   | `docs/project-map.md`                |
