# Поселения: частые ловушки

> **Что это.** Контракт домена поселений и правила гейтинга. Код — `entities/settlement/`, `features/settlements/`.

## Данные

- `GET .../roles` и `GET .../members` **не существуют**: роли и состав приходят внутри `Settlement`.
- Мутации возвращают `{ settlement }` → перерисовывайте из ответа мутации, без дозапроса.
- `Settlement.leader` — `@deprecated`. Владельцы — члены, у которых `role_ids` содержит `'owner'` (`OWNER_ROLE_ID`).
- `members` **уже включают владельцев**: никаких `members.length + 1`.
- Обязательные поля тела в мутациях ролей/владения/контактов — без них `INVALID_ARGUMENT`.
- Чтение `attachments[0].url` — только с optional chaining (вложения бывают пустыми).

## Безопасность

- `role.name` и `contact_info` выводить **только интерполяцией `{{ }}`** — сервер не экранирует (XSS).
- Клиентская валидация: имя роли 1–64, контакты ≤512, запрет символов `<` и `>`.

## «Гильдия» — фронтовый костыль

- Маркер `[GUILD]` в `name`, режется хелперами `entities/settlement/lib/` (`is-guild-*`, `get-settlement-display-name`, пайп `settlement-display-name`).
- На бэк уходит `type: 'CAMP'`; шкала уровней и кнопка повышения гильдии не показываются.
- Так задумано (см. `docs/history.md` §3.1): не «исправляйте», не убирайте маркер, пока бэкенд не получит тип.

## Гейтинг кнопок

| Действие                                    | Условие                                   |
| ------------------------------------------- | ----------------------------------------- |
| Инвайты                                     | `owner ∨ PERMISSION_INVITE_MEMBER`        |
| Заявки                                      | `owner ∨ PERMISSION_REVIEW_JOIN_REQUEST`  |
| Роли, контакты, владение, картинка, уровень | только `isOwner`                          |
| Кик                                         | `isOwner ∨ admin`                         |
| Выход                                       | не-owner (или owner при втором владельце) |

Чистые функции гейтинга покрыты тестами (`entities/settlement/lib/*.spec.ts`) — менять с оглядкой и прогонять `npm test`.
