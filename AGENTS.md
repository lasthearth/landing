## Стек

Angular 20 (standalone, signals) · TypeScript 5.9 strict + strictTemplates · LESS + Tailwind CSS v4 ·
Taiga UI 4 · `@angular/build:application` (Vite) · SSR + пререндер из `app.routes.server.ts` · OIDC (Logto) ·
`HttpClient` с fetch + интерцепторами · состояние — сервисы и сигналы, без NgRx.

## Жёсткие правила

1. Новый код — по FSD. Импорт между слайсами только через `index.ts` слайса, слои — только вниз (`npm run arch`).
2. `shared` не знает о домене; `core` — сквозной слой (ему можно `entities`/`features`).
3. Только standalone-компоненты, `ChangeDetectionStrategy.OnPush`, селектор `app-*`. `NgModule` не создаём.
4. Один файл — одна сущность; JSDoc на русском у каждого публичного элемента (`@param`, `@returns`).
5. Цвета и движение — только токены `--lh-*`; тёмная тема переопределяет значения переменных, а не селекторы.
6. Любой новый текст — сразу в обе локали: `npm run i18n -- set <домен> <ключ> "<текст>"`, проверка `npm run i18n -- check`.
7. HTTP — через сервисы слоя, базовый URL из `environment.apiUrl`; `Bearer` добавляет `authInterceptor`.
8. Серверный текст выводим интерполяцией `{{ }}` — сервер его не экранирует.
9. Decimal-поля (`coins`, `price`, `reward_coins`) — строки и в DTO, и в UI.
10. Бизнес-логика — в сервисах и сторах, не в компонентах.
11. `any`, `console.log`, хардкод URL; правки `node_modules` и `dist` — не используем.
12. Тяжёлые виджеты — через `@defer (on idle)`; режим рендера роута — в `src/app/app.routes.server.ts`.

## Проверка

```bash
npm run verify        # обязательный минимум: формат доков, бюджет, указатели, FSD, локали, контраст, типы
npm run verify:full   # плюс ng build и тесты (нужен Chrome)
npm run map           # перегенерировать карту навигации
```

Правки текста — `npm run i18n -- get|set|find` (словарь `rules.i18n.ts` — 222 kB, читать его целиком не нужно).

## Порядок работы

1. Определить слой и слайс (`docs/ARCHITECTURE.md`), найти существующее в `docs/project-map.md`.
2. Прочитать указатель под свою ветвь задачи из таблицы выше.
3. Внести правку; текст — через `npm run i18n`; границы — `index.ts`.
4. Прогнать `npm run verify`; проверить, что шаг, который вы затронули, реально зелёный.
5. Создали или перенесли файлы — `npm run map`. Приняли решение с обоснованием — запись в `docs/history.md`.
6. Коммит в стиле `LH | feat: ...` / `fix: ...` / `ux: ...` (в своём терминале: `git` не пишет в песочнице).
